Privacy Policy – Sri's Workbench (Personal Stylist)

Last updated: November 12, 2026

Sri's Workbench is a personal, non-commercial, open-source wardrobe application that uses Pinterest boards as fashion inspiration to generate outfit recommendations based on clothes I own.

The application is developed solely for personal use and is not currently offered as a public service.

Information Usage

The application accesses my authorized Pinterest boards and pins, along with clothing images and descriptions added to my digital wardrobe. This information is used only to analyze fashion inspiration and generate outfit recommendations.

Data & Security

The application's source code is publicly available on GitHub. API keys, access tokens, and other private credentials are not included in the public repository.

Personal data and Pinterest information are not sold or shared for advertising purposes.

Third-Party Services

The application uses the Pinterest API. If external AI services are used, relevant images or information may be processed by those services to generate recommendations.
